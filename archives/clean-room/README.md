# Clean Room Project Archive

이 폴더는 반도체 클린룸 모니터링 및 제어 시스템 프로젝트 관련 자료를 정리하기 위한 위치입니다.

`Clean_Room.zip`은 원본 프로젝트 압축 파일이며, 용량이 커서 GitHub 웹 업로드 또는 Git LFS 방식으로 직접 업로드하는 것을 권장합니다.

## 업로드 예정 파일

- `Clean_Room.zip`

## 포트폴리오 연결 목적

이 프로젝트는 WPF 3D 그래픽스와 TwinCAT/ADS PLC 통신을 활용하여 반도체 클린룸의 온습도, 기압, 파티클, 거리 센서 모니터링 및 상태 제어 시나리오를 검증하는 HMI 시스템입니다.
