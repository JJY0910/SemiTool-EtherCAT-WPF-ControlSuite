# Demo Image Placeholders

Add portfolio screenshots and demo media here after running the WPF HMI locally.

## Expected files

- `dashboard.png`
- `manual-control.png`
- `io-monitor.png`
- `auto-sequence.png`
- `wafer-flow.png`
- `alarm-log.png`
- `settings.png`
- `simulator-demo.gif`

## Optional media

- `real-hardware-short-test.mp4`

Do not commit huge videos directly. Use compressed GIFs, GitHub Releases, or an external video link if needed.

## Recommended capture order

1. Start the app in Simulator mode.
2. Connect the simulator.
3. Capture Dashboard.
4. Capture Manual Control.
5. Toggle simulator inputs in I/O Monitor.
6. Stage or run Auto Sequence view.
7. Trigger a safe simulator alarm/reset case.
8. Capture Alarm & Event Log.
9. Add approved real-hardware media only after supervised commissioning.

## Privacy rule

Do not add real equipment photos or videos that expose private school, customer, or machine details unless they are approved for public portfolio use.
