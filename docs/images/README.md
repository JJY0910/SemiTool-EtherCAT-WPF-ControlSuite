# Demo Image Placeholders

Add portfolio screenshots and demo media here after running the WPF HMI locally.

## Expected Files

- `dashboard.png`
- `manual-control.png`
- `io-monitor.png`
- `auto-sequence.png`
- `alarm-log.png`
- `simulator-demo.gif`

## Recommended Capture Order

1. Start the app in Simulator mode.
2. Connect the simulator.
3. Capture the Dashboard and Manual Control screens.
4. Toggle simulator inputs in the I/O Monitor.
5. Run or stage an Auto Sequence view.
6. Trigger a safe simulator alarm/reset case for the Alarm & Event Log screen.

## Public Portfolio Caution

Do not add real equipment photos or videos that expose private machine details unless they are approved for public portfolio use.
